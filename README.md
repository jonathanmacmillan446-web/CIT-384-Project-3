# CIT 384 - Project 3

Chrome DevTools Part One. This is a copy of my Project 2 (Jim, the Giga Pet shark) with examples added for
console logging, browser-logged messages (404, TypeError, Violation), console filtering, and debugging a bug
with breakpoints in the Sources panel.

You can view the published website here:
[Live Website on GitHub Pages](https://jonathanmacmillan446-web.github.io/CIT-384-Project-3/)

DevTools Practice buttons.
